# Taipy

1. Identify installed Taipy version and whether the app uses GUI, scenario orchestration, or both. Trace page variables, callbacks, and data nodes to their sources.
2. Keep per-session values in the documented state mechanism and manage task outputs through existing scenario configuration. Keep longer runs off interactive callbacks when the app supports background work.
3. Run the app from its actual entry point. Verify a control changes the intended display, scenario submissions are traceable, and failure is presented without overwriting a successful result.

Report the files changed, verification run, and any unavailable environment or access.
