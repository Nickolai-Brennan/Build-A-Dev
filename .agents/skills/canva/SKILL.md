# Canva

1. Identify the deliverable and surface. For a design, confirm dimensions, audience, format, brand and approved assets. For code, select the supported in-editor or REST integration surface and inspect the current docs.
2. Use the design's existing template where appropriate. For integrations, rely on supported scopes and auth flows, keep credentials out of client code, and handle SDK or API errors.
3. Verify readability, text fit, asset fidelity and output dimensions in the actual design or export. For integrations, exercise an authorized workflow with a test asset and record its result.

Report the files changed, verification run, and any unavailable environment or access.

[Product documentation](https://www.canva.dev/docs/)
