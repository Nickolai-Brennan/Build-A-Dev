# RAWGraphs

1. Inspect data columns, types, row grain, missing values and aggregation. Choose a RAWGraphs chart based on the analytic question and available dimensions.
2. Record column-to-channel mappings, sorting, palette, scale and layout choices. Use approved sample or anonymized data if the workspace or destination is shared.
3. Save the project configuration and requested export where available. Reopen the result and reconcile totals, labels and visual grouping with the source.

Report the files changed, verification run, and any unavailable environment or access.
