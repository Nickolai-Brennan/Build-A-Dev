# React

1. Inspect the React version, router, rendering mode, and existing component and test conventions. Decide which state belongs in the URL, parent, form, or server cache.
2. Use stable keys and derive values during rendering. Use effects for synchronization with external systems, with cleanup when needed. Keep boundaries appropriate for the existing renderer.
3. Verify loading, empty, error, and success paths as applicable. Test keyboard/focus behavior and build the app through its normal entry point.

Report the files changed, verification run, and any unavailable environment or access.
