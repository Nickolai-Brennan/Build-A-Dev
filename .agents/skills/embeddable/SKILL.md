# Embeddable Developer Toolkit

1. Inspect the workspace, toolkit version, starter conventions, embed target and analytics model grain. Identify which definition belongs to a model, component, dashboard, or host app.
2. Reuse existing dimensions and measures, configure typed component inputs, and preserve tenant restrictions in the supported backend access and token flow. Keep sensitive credentials server-side.
3. Verify dashboard rendering and filters with representative data in a preview workspace. Exercise empty/error states and two differently scoped tenants before release.

Report the files changed, verification run, and any unavailable environment or access.
