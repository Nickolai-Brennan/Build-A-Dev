# Storybook

1. Read the installed Storybook framework, configuration, and story conventions. Put shared providers in existing decorators and isolate test data from live services.
2. Use args for public component inputs and stories for distinct states. Add interaction assertions through the project's supported play/test API and mock network dependencies where needed.
3. Build or run Storybook using repository scripts. Verify representative states and interactions in the installed browser/test environment.

Report the files changed, verification run, and any unavailable environment or access.
