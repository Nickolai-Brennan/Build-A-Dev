# ApexCharts

1. Identify the library and wrapper version, deployment license terms, chart type, series schema, units, and date handling. Preserve the distinction between missing and zero.
2. Use the appropriate series and axis format and scoped chart IDs when coordinating charts. Use lifecycle cleanup or the existing wrapper and handle client-only rendering where required.
3. Validate sample values against input data. Test resize, filter updates, empty data and keyboard-accessible access to chart values.

Report the files changed, verification run, and any unavailable environment or access.
