# Build-A-Dev

Reusable skills and development workflows for ChatGPT, Codex, and GitHub Copilot.

| Skill | Use it to |
| --- | --- |
| [Agent Building](.agents/skills/agent-building/SKILL.md) | Create or adapt a portable skill and verify its behavior. |
| [Environment Pre-Code Activation](.agents/skills/environment-pre-code-activation/SKILL.md) | Prepare the stack, dependencies, editor, and project locations before coding. |
| [Data Visualization](.agents/skills/data-visualization/SKILL.md) | Choose a chart, define its data, and verify displayed values. |
| [API Contracts](.agents/skills/api-contracts/SKILL.md) | Design a typed HTTP API and wire a frontend to it. |
| [MCP Tool Design](.agents/skills/mcp-tool-design/SKILL.md) | Define a tool for a backend capability and test its calls. |

Read [Building Skills 101](building-skills-101.md) for authoring and client setup.

## Open the workspace

Open [Build-A-Dev.code-workspace](Build-A-Dev.code-workspace) in VS Code. Build-A-Dev is a developer tooling repository. Use the Environment Pre-Code Activation Skill in each application repo to generate or update that app’s dependency files and setup.
